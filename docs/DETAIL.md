# 答题浮卡（Answer card）

## 它做什么

任何会话调用 `ask_user_question`（或别的路径触发 `user-questions/request`）时，宿主把这道题挂起来，浏览器右下角弹出一张浮动卡片：显示会话标题、问题原文、全部选项。点一下就答了，不需要切回那个会话。

- **多会话**：每个会话各占一条，不再像鲸鱼挂件的单槽位那样被别的会话覆盖。
- **点选即答**：单选题点选项直接提交；多选题勾完点「提交」。
- **自己输入**：每道题下面有输入框，回车即提交自定义答案。
- **在会话里答**：想走官方界面，点「在会话里答」把这道题交还给 DSH 自己的提问卡片。
- **跳过**：按跳过提交空的 `selected`，等于用户跳过这题。
- **10 分钟没人答**：自动交还给官方界面，避免模型对着空气干等。
- **提示音**：来新题响一声（浏览器要求先有一次点击才能出声）。

## 怎么用

装着就行，没有设置页。卡片自己出现、自己消失。

## 已知限制

- 只接**提问**（`user-questions/request`）。授权确认（`approval/request`）还没接。
- 卡片在浏览器窗口里，不进系统托盘，也不发系统通知：DSH 窗口不在前台时只能靠声音。
- 卡片内容按问题原文与选项标签渲染，选项的副标题只在宿主提供 `description` 时显示。
- 宿主注入只在 `webserver/index-inject` 这条通道上（桌面端唯一可靠通道）；纯命令行 `dsh web` 形态靠 `tapIndex` 兜底。
- 诊断日志写在 `~/.dsh/qq-card-diag.log`：`intercept` 行代表宿主抢到了这道题，若从没出现过，说明监听没挂上。
